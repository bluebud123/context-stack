# Context Stack

A precision interrogation method for using AI to make the most compounding progress possible on any topic in the next 48 hours.

**One static HTML file. No build, no server, no accounts.** Open the file in your browser, configure once, and every prompt adapts to your topic, role, depth, goal, and chosen Mode.

## What it does

You upload a curated stack of sources (textbook, papers, your notes, one contrarian source) into NotebookLM or Claude.ai, then run a sequence of prompts that:

1. Surface the mental frameworks experts actually use
2. Identify the live disagreements in the field
3. Force you into active recall under pressure
4. Consolidate what you learned into a one-page reference

Built on cognitive science: active recall, desirable difficulty, generative learning. Inspired by the MIT Challenge / ultralearning literature.

## The Mode dimension

Different topics have different shapes. One protocol can't fit all of them. Pick the Mode that matches the *shape* of what you're learning:

| Mode | Best for | What 48h delivers |
|------|----------|-------------------|
| **🧭 Explore** | "I want to learn something but don't know what" | Topic + Mode picked, ready to commit |
| **🎓 Exam** | Professional exams, interviews, declarative mastery | Exam-ready / interview-grade understanding |
| **🎯 Skill** | Languages, instruments, sport, drawing, motor skills | First plateau — real conversation, real song, recognisable form |
| **🎨 Creative** | Writing, design, composition, art-making | First stylistic breakthrough — moves start showing up |
| **🛠 Project** | "Ship a weather station," operator, paper, side-product | A shipped v1 of a real artifact |
| **📜 Socratic** | Humanities, philosophy, ethics, narrative history | A position formed, pressed, defendable |
| **🩺 Diagnostic** | Medicine, troubleshooting, forensic, casework | Working pattern library + sharpened DDx reflex |

Each Mode swaps the prompt set, the presets, the source checklist, and the walkthrough. The stress register changes too — Examiner (PASS/BORDERLINE/FAIL) for Exam, Coach (one correction at a time) for Skill, Studio Critique (Working / Pretending / Cut It) for Creative, Pair Practitioner for Project, Dialogue (Sharper / Same / Slipped) for Socratic, Case Rounds (Reasonable / Risky / Wrong on the *reasoning trace*) for Diagnostic.

## The Time Track dimension

48 hours is a frame, not a marathon. Pick the track that fits your reality:

- **Crash · 4–6h** — essentials only
- **Sprint · 12h** — half a weekend
- **Standard · 48h** — the full protocol, spread however you want
- **Block · 2 weeks evenings** — for skills, creative work, projects (~30–40h spread)
- **Sustained · 60 days+** — for languages, instruments, deep domains

## Use it

Just open `context-stack-public.html` in any modern browser. No install, no build.

100% local — your topic, role, audience, depth, goal, and saved stacks live in `localStorage` on your device only. The only data that leaves your computer is what you copy and paste into your AI of choice (and that goes to *them*, not us).
